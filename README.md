 # Projects

A collection of web development projects built with HTML, CSS, JavaScript, and Node.js. Each project is self-contained in its own folder.

---

## Projects

### Drum Kit
An interactive drum kit that plays sounds on keyboard key presses or mouse clicks. Built with HTML, CSS, and vanilla JavaScript using the Web Audio API.

### Simon Game
A browser-based implementation of the classic Simon memory game. The game generates a growing sequence of colored button flashes that the player must replicate in the correct order.

### Stone Paper Scissors
A two-player game (player vs computer) of rock-paper-scissors. The computer makes a random choice each round and the result is displayed on screen.

### Tic Tac Toe
A two-player tic-tac-toe game playable in the browser. Detects wins and draws and allows players to restart the game.

### To Do List
A task management app where users can add, check off, and delete tasks. Built with HTML, CSS, and JavaScript.

### Currency Converter
Converts amounts between different currencies. Fetches live or static exchange rate data and displays the converted value.

### Link to QR Code Project
Generates a QR code from any URL entered by the user. Built with Node.js and a QR code generation library.

### Blog App
A full-stack blog application built with Node.js, Express, and EJS templating. Allows users to create, view, and manage blog posts.

---

## Tech Stack

- HTML, CSS, JavaScript (frontend)
- Node.js, Express, EJS (backend / blog app)
- npm (package management)

---

## Getting Started

Clone the repository:

```bash
git clone https://github.com/shubhamwankhede658/Projects.git
cd Projects
```

For frontend-only projects (Drum Kit, Simon Game, Stone Paper Scissors, Tic Tac Toe, To Do List, Currency Converter), open the `index.html` file directly in a browser.

For Node.js projects (Link to QR Code, Blog App), navigate into the project folder and run:

```bash
npm install
node index.js
```

Then open `http://localhost:3000` in your browser.
